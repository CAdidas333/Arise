Arise is a fully deployed, mobile-friendly browser RPG built in a single session with Kevin. All core systems are live — combat, dungeons, shadow extraction, procedural audio, mobile controls, PWA install, save/load. Phase 1 is complete. Phase 2 (skill tree, leaderboard, more content) is next.

What's Built

  • ✓ Hybrid ARPG combat — WASD + mouse, 5 abilities, cooldowns, combos
  • ✓ 5 dungeon gates (E–A rank) with wave system + boss hunt finale
  • ✓ Shadow extraction — defeat bosses, build a shadow army
  • ✓ Shadow AI — engage only when player is fighting; Legion berserk mode
  • ✓ Stat allocation — STR/AGI/INT/VIT/PER, 5 pts/level, auto-assign
  • ✓ Hunter rank progression (E → S based on level milestones)
  • ✓ Procedural audio — Web Audio API battle music + 10+ SFX
  • ✓ Mobile touch controls — virtual joystick + skill buttons
  • ✓ PWA manifest + fullscreen + iPhone safe areas
  • ✓ Save/load via localStorage, high scores, daily + bonus quests
  • ✓ Pause menu with volume sliders, minimap, dev mode
  • ✓ GitHub Pages auto-deploy — live at cadidas333.github.io/Arise

Key Technical Notes

Zero-dependency constraint: No npm, no bundler, no frameworks. The entire game is a single index.html. This is non-negotiable — it's a showcase project.
Dev mode: Press backtick (`) for +5 levels, Shift+backtick (~) for -5 levels. Hidden from UI, used for rapid testing.
Shadow AI rules: Shadows only attack when player is actively fighting AND moving. "Arise: Legion" (key 5) overrides this for 12 seconds of berserk mode. Standing still for 10s+ causes shadows to disengage.
Solo Leveling IP: Fan game, not for commercial distribution. Repo is public for showcase purposes only.
